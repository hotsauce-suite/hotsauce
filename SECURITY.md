# Security

Please don't open a public issue for a security problem. Report it privately through GitHub: **Security → Report a vulnerability** on this repository. Include the steps to reproduce it and what an attacker could do.

You'll get an answer within a few days. Once a fix is out, we'll credit you unless you'd rather we didn't.

What's in scope: the server, the web app, the setup wizard and its token, how saved keys are stored, the MCP server, the Chrome extension and the Mac app. If you run your own instance, keep it updated, and keep `HOTSAUCE_MASTER_KEY` and the data volume private.
