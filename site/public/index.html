The open sauce office suite.

Docs, meeting notes, dictation and screen recordings for a small team, on a server you run. Every doc and note is a plain Markdown file in git, so nothing is locked in.

Set it up for your team View on GitHub

Four apps, one small server

They share sign-in, search and your brand, and an MCP server lets Claude and other agents work with your docs and meetings as you.

Docs

Markdown with a source-first editor, live collaboration through git, full history, search, and links that survive renames.

Meetings

AI notes for Google Meet or any call in the browser: live transcript, notes built from your own jottings, and Ask across past meetings.

Dictate

Hold a key on your Mac, talk, and clean punctuated text lands where your cursor is. Team word lists keep names spelled right.

Clips

Screen recordings with a camera bubble, transcripts, speed control and a shared library for the team.

Why teams pick it

The things a hosted suite can't promise.

Your files stay yours

Docs and notes live as Markdown in a git repository on your server or in your GitHub organization. The database is only a cache.

Your keys, your bill

Bring your own Anthropic and Deepgram keys. A small team spends a few dollars a month on them, with no per-seat pricing.

Your brand

Name the workspace after your company and set your logo, colors and fonts. The whole app follows, and agents can read the brand kit.

One small server

One process and one disk. About $6 a month on Fly.io, or any machine that runs Docker.

Run it for your organization

About ten minutes. A setup wizard does the rest in your browser.

Get the code. You need Node 22, git and pnpm (corepack enable).

git clone https://github.com/hotsauce-suite/hotsauce
cd hotsauce
pnpm install

Launch a server on Fly.io, named after your team.

scripts/deploy-fly.sh acme-office

Or on any Docker host: cd deploy && docker compose up -d --build

Open the setup link the server prints. The wizard walks you through your organization, brand, Google sign-in (with a free Clerk account), AI keys and storage, then launches.

The full guide is docs/self-host.md.
