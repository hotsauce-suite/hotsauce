No lock-in

Your files are just files.

Most office software keeps your work in a database only it can read. Hotsauce keeps it in a git repository, as Markdown anyone can open.

Leave whenever you like

Every doc, meeting note and transcript is a Markdown file with its full git history. Keep them in your GitHub organization and your export is git clone.

Use the tools you already have

With GitHub storage, open the repository in Obsidian, VS Code or any editor. Changes you push show up in Hotsauce.

Keep it where you choose

On the server's own disk, or in your GitHub organization. For docs and meetings, the database is only an index you can delete and rebuild.

Self-host

Running this afternoon.

You run three commands. A setup wizard in your browser does the rest, and nobody edits a config file.

The wizard covers

  • Your organization
  • Brand
  • Google sign-in
  • AI keys
  • Files and audio
  • Review and launch
You'll need a Fly.io account (or any server with Docker), a free Clerk account for Google sign-in, and optionally Anthropic and Deepgram keys for the AI features and a Cloudflare R2 bucket for Clips. Docs works fully without them.

  1. Get the code

    git clone https://github.com/hotsauce-suite/hotsauce
cd hotsauce

  2. Launch your server

    Needs Node 22, pnpm (corepack enable) and flyctl, signed in with fly auth login. The script creates the app and its disk, generates the server's keys, deploys, and prints your setup link.

    pnpm install
scripts/deploy-fly.sh acme-office

  3. Open the setup link

    Name your workspace, add your brand, connect sign-in and keys, and launch. Then send your team the link. Full guide in docs/self-host.md.

Questions

Good to know.

Who is Hotsauce for?

Teams of roughly 5 to 50 people who want their documents and meeting notes on infrastructure they control, without paying per seat. You need one person who is comfortable running three commands. After that, everything is set up and managed in the browser.

Is it really free?

Yes. The code is free under AGPL-3.0 and every feature is included. You pay your own hosting (about $6 a month on Fly.io) and, if you turn them on, your own Anthropic, Deepgram and Cloudflare R2 usage.

What does AGPL-3.0 mean for my company?

You can run Hotsauce for your team, change it, and keep using it, with no fees. If you offer a modified version to people outside your organization over a network, you have to share your changes under the same license. Using it internally doesn't trigger that.

Do I need the AI keys?

No. Docs and search work fully without them. A Deepgram key turns on meeting transcripts and Dictate. An Anthropic key turns on AI meeting notes, Ask, and Dictate's clean-up of filler words. The app shows what each key turns on, and admins can add keys at any time in Settings.

Where does my data go?

Your files live on your server, or in your GitHub organization if you choose that. Audio is sent to Deepgram for transcription and text to Anthropic for notes, using your own accounts. Kept meeting audio can go to your own Cloudflare R2 bucket, or not be kept at all.

How do people sign in?

With Google, through a free Clerk application that the wizard walks you through. The server only lets in email addresses from the domains you choose.

Does a bot join my meetings?

No. Meetings records from your own browser tab or the Chrome extension for Google Meet, so there's no extra attendee in the call.

How do I update it?

Pull the latest code and run the same deploy command again, with the same PUBLIC_URL if you set one. It's safe to rerun, and your files and settings stay on the server's disk.
