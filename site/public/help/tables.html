Tables

Tables is a simple spreadsheet for trackers, lists and budgets. Formulas work the way they do in Excel and Google Sheets.

Use it

  • New table, then give each column a type: text, number, date, checkbox, choice, person or link.
  • Type = to write a formula, like =SUM(C2:C20) or =C2*D2.
  • Arrow keys and Tab move around. Enter or F2 edits a cell, and typing replaces it.
  • Copy and paste to and from Google Sheets and Excel.
  • Import a CSV, TSV or Excel file (the first sheet). Download any table as CSV or Excel.

Good to know

  • One person edits a table at a time. If two people save at once, the second is asked to reload.
  • A table keeps its values and formulas, not colors, bold or number formats.
  • Tables can hold up to 5,000 rows and 52 columns.
What it needs

Nothing extra.
