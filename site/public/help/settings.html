Settings and notifications

Settings is where you set things up for yourself on this device. On a computer, click the gear at the bottom of the left bar, or your initials and then Settings. On a phone, tap Apps, then Settings.

What’s in Settings

Account
Your initials, name and email, and Sign out. Sign out lives only here.
Install app
An Install button for this phone or computer. Shows Installed when you’re using the installed app. See Install it.
Notifications
The Notifications on this device switch covers everything Hotsauce sends: a reminder a minute before meetings, timed tasks when they’re due, check-in questions, and your daily briefing. Once it’s on, Send test notification sends a real one to every device you’ve switched on, so you can check it arrives.
Appearance
Light, dark, or match your device. It’s saved per device.
Mac app and Chrome extension
The Mac app download, and a link to set up the Chrome extension.
Connect Claude
Make a personal token so Claude and other AI tools can work with your Hotsauce. See Connect Claude and other agents.
Calendars
Which of your Google calendars Meetings reads. Your main calendar is always on; tick any others.
Help
Send feedback if your admin turned it on, and links to the Help center and the FAQ.
About
The version you’re running. New versions install themselves; Reload picks one up right away.

Admins also see Organization, for workspace-wide settings. See Run Hotsauce for your team.

Turn on notifications

  1. Open Settings.
  2. Turn on Notifications on this device and allow notifications when your browser asks.
  3. Press Send test notification. You should see it within a few seconds.

Each phone and computer is set up on its own. If Settings says notifications are blocked, allow them for Hotsauce in your browser’s site settings, then come back. If the test says it couldn’t reach a device, try again in a minute. On an iPhone, add Hotsauce to your home screen first.
