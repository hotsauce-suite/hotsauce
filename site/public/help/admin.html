Help / For admins

Run Hotsauce for your team

Admins manage the whole workspace in Settings → Organization. Only admins see it. Changes take effect when you apply them.

What each key turns on

KeyTurns onWhere to get it
AnthropicMeeting notes, Ask about meetings, Dictate clean-up, summaries, the daily briefingconsole.anthropic.com
DeepgramTranscripts for meetings and clips, Dictate, voice notes, Rambleconsole.deepgram.com
OpenAI*Reading the daily briefing aloudplatform.openai.com
Cloudflare Turnstile*Public forms and booking links, kept free of botsCloudflare dashboard

Add the Anthropic and Deepgram keys in Settings → Organization → AI and transcription. Each has a Test button, and keys are stored encrypted and never shown again. *The OpenAI and Turnstile keys are set on the server itself (OPENAI_API_KEY, TURNSTILE_SITE_KEY and TURNSTILE_SECRET_KEY; see the self-hosting guide). Without a key, the features that need it say so, and everything else keeps working.

Who can sign in

  • Email domains that can sign in: anyone with a Google account on these domains gets in.
  • Invited people: exact email addresses outside those domains. They sign in with a code sent to their email, and see everything the team can.
  • Admins: the people who can open Settings → Organization.

Your brand

Name the workspace, add a logo and icon, and pick colors, fonts and a default light or dark look. Every app follows, and agents can read the brand kit too. How your organization writes tells the AI how your team sounds.

Chat rooms and sharing

  • Team chat link puts your chat on everyone's left bar (it's pinned to start; each person can unpin it) and in the app grid.
  • Chat rooms: add a Slack-compatible webhook so Forms and Check-ins can post to it.
  • Read-only links: let anyone with a shared link read it without signing in. Off by default.

Updates

On Fly.io with a Fly token, Hotsauce can update itself: Settings → Organization → Updates installs each new release within a few hours, never while a meeting is being recorded. Turn it off to update only when you press Update. With Docker, run docker compose pull then docker compose up -d. Copies made from GitHub get a weekly pull request with the newest release.

Backups

With storage set up (Cloudflare R2 or any S3-compatible bucket), the server backs itself up every day to your own bucket. Recent backups are listed in Settings → Organization.

To be told when a backup fails, point an uptime monitor such as Better Stack or UptimeRobot at /api/health/backup on your server's address. It turns red when the newest backup failed or none has worked for 26 hours.
