# Code of conduct

Hotsauce follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind and patient, assume good intent, and keep criticism about the work. Harassment, personal attacks and discriminatory language aren't accepted anywhere in the project.

To report a problem, contact the maintainers privately through GitHub (**Security → Report a vulnerability** works for this too). Reports are kept confidential.
